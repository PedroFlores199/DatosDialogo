Datos reales, preguntas concretas

Las tablas proceden de la captura del INE de TurismoLakehouse. Hay hoteles por provincia y mes, gasto y mercados por región, viviendas por captura semestral y una previsión orientativa de pernoctaciones.

No hay gasto ni viajeros británicos por provincia, datos meteorológicos cargados, empresas, clientes o estadísticas de personas. El analista debe rechazar esos desgloses.

Comprueba la consulta

Un modelo puede elegir una columna o una agregación incorrecta aunque el SQL sea válido. Revisa las columnas, el periodo y el SQL desplegable antes de utilizar una cifra. Las tablas y los gráficos muestran el resultado que devuelve PostgreSQL.

Una conversación temporal

Se conservan hasta cinco preguntas y sus consultas en la sesión, durante un máximo de treinta minutos de inactividad. «Nueva conversación» borra ese contexto. Los informes pertenecen al último resultado disponible y no se guardan en el servidor.

Límites de ejecución

El usuario de consulta solo tiene permiso de lectura. El SQL se valida antes de ejecutarse, tiene un límite de tiempo de 2,5 segundos y devuelve como máximo 200 filas. Se permite un intento de corrección. Solo se atiende una pregunta cada vez en esta demostración.
